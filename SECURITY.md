# Security Policy

## Reporting a Vulnerability

Do not report suspected security vulnerabilities in a public GitHub issue.

If GitHub's private vulnerability reporting ("Report a vulnerability" under this
repository's Security tab) is enabled, use it. If it is not available, open a
minimal public issue asking for a private contact channel — do not include
vulnerability details, exploit steps, credentials, or other sensitive evidence
in that issue. Full details can then be shared once a private channel is
established.

When reporting, please:

- do not include real credentials or secrets in your report;
- do not test against systems or accounts you do not own or do not have
  explicit authorization to test;
- include the affected version or commit and the minimal information needed
  to reproduce the issue, shared through the private channel where possible.

This project does not currently offer a bug bounty, guaranteed response times,
or a formal disclosure SLA.
