## 2. `src/lib/ingress-protocol.ts` — recommend HOLD (one missing test, then approve)
Diff: adds `LAB_INGRESS_ENVIRONMENT = "cloud-run-lab"`, widens the payload `environment` field to accept it, and changes the POST mutation-policy host pin from `value[8] !== "limitmark.com"` to `(value[2] === INGRESS_ENVIRONMENT && value[8] !== "limitmark.com")`. So the structural validator now accepts a lab payload with ANY syntactically valid host; the `limitmark.com` pin still applies to every production-environment payload. Authorization semantics are not decided here: the real gate is `verifyMutationIngress` (`src/lib/ingress-verifier.server.ts`), which requires `payload[2]` to equal the environment of the server-configured policy (production by default, lab only when `LIMITMARK_RUNTIME === "cloud-run-lab"` selects the lab policy), plus audience, deployment, freshness, method, scheme, host header equality with `publicHostname`, and a signature under keys the policy holds. A lab-signed payload therefore fails against a production policy (environment mismatch) and vice versa. Fail-closed behavior preserved (unknown environment still `fail("environment")`).
Callers (13 production modules, among them `admission-client.server.ts`, `ingress-verifier.server.ts`, `ingress-signer/signer.ts`, `public-inquiry-handler.server.ts`) and 12+ tests; lab coverage: `ingress-verifier.test.ts` (lab payload accepted by lab policy), `lab-verifier-gate.test.ts`, `lab-hostname-gate.test.ts`, `lab-isolation.test.ts`.
Missing test (why HOLD): no test pins the protocol-level invariant directly: a `production` environment POST payload with a non-`limitmark.com` host still fails `mutation-policy` in `validatePayload`/`encodeIngressPayload`, and a payload with an unrecognized environment still fails. The relaxation is correct by inspection, but this is a shared production module and the invariant that the production pin survives the change should be tested, not inspected. Also confirm the lab host is bound elsewhere (it is: verifier `payload[8] !== publicHostname`). The registry hold `shared-production-module` stands until that test exists.
